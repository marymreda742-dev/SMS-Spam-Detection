
# SMS Spam Detection

## Project Overview
This project uses Machine Learning to classify SMS messages
as Spam or Not Spam.

## Dataset
The project uses the SMS Spam Collection dataset.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Naive Bayes
- Google Colab

## Model
Multinomial Naive Bayes

## Evaluation
The model achieved approximately 98% accuracy on the test set.

## How It Works
1. Load the SMS dataset.
2. Convert text messages into numerical features.
3. Split the data into training and testing sets.
4. Train the machine learning model.
5. Predict whether new messages are spam.
